🚗 Road Accident Analysis Dashboard
📊 Overview
The Road Accident Analysis Dashboard is an interactive Power BI project aimed at analyzing road accident patterns, casualties, and contributing factors across the UK. The dashboard provides a comprehensive visualization of accident-related data categorized by severity, location, vehicle type, lighting conditions, road type, and more.

🧾 Objective
To uncover insights into the volume and severity of road accidents, enabling stakeholders such as policymakers, transportation authorities, and safety departments to make informed decisions to improve road safety.

📂 Dataset Details
Source: [Likely from UK Department for Transport or similar open datasets]

Time Period: Comparison of CY (Current Year) vs PY (Previous Year)

Key Columns:

Casualty count

Accident severity

Vehicle type

Location (Map)

Road type

Light conditions

Urban vs Rural classification

Weather and road surface filters
